# Open the GreenRev TypeScript upgrade

This is version **0.4.1**, extending the earlier TypeScript foundation.

- The real project files are in `src/`, `ui/`, `web/`, `tests/`, `migrations/` and `contract/`.
- `README.md` explains what works and how to run it.
- On Windows, use Node.js 24, unzip everything, then double-click `start-demo-windows.bat`.
- The demo address is http://localhost:3100.
- Start with Rentals, then switch to Parts and Haulage to see how the menus differ.
- New subscriber demonstrates selecting only the services a business needs.
- Your developer should read `docs/DEVELOPER_HANDOVER.md` before merging.
- Final approved selling prices have not been invented. Use the pricing administrator to configure them.

The live application, hosting and database have not been changed by receiving this package.

Already using v0.4.0? Follow docs/UPDATE_V0.4.0.md. Copy the updated contents into the existing project folder and restart the demo; do not delete the saved database.
